Stars.exe ⭐

A small CLI game made in 50 minutes at 5 AM.

``` 🚀 Run the game ```

git clone https://github.com/imseggy/Stars.exe.git
cd stars.exe
g++ main.cpp -o stars.exe
./stars.exe

``` 🎮 Controls``` 

Left / Right Arrow Keys → Move
SPACE → Capture the point

``` 💾 Save System```

Your high scores are automatically saved in:

highscore.txt
